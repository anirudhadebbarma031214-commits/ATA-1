# ATA-1 — 3D Open-World Game

A Windows PC 3D game project built with Godot 4.

## Current starter build

- Basic 3D test scene with a ground plane, player, light, and follow-style camera placement
- Basic player movement and jump script
- Lightweight Godot Compatibility renderer for broader hardware support

## Open the project

1. Install **Godot 4.3 or newer** from https://godotengine.org/download/windows/
2. Download this repository using **Code → Download ZIP**, then extract it.
3. Open Godot and choose **Import**.
4. Select the extracted folder containing `project.godot`.
5. Press **F6** to run the current scene or **F5** to run the project.

## Controls

The project uses these input actions: WASD / arrow keys to move, Space to jump. Configure these actions in **Project → Project Settings → Input Map** if they are not present yet.

## Important

This is only the initial playable foundation, not a finished open-world game. The next development steps should be decided together: game setting, player character, camera, map, vehicles, missions, and visual style.
